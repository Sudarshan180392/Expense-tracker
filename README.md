# 💰 FinTrack (React)

A modern expense tracking application built with React to manage budgets, track expenses, and visualize spending patterns.

## 🚀 Features
- Add / delete expenses
- Budget tracking
- Category-wise insights
- Charts (Recharts)
- Persistent storage (localStorage)
- Responsive UI

## 🛠 Tech Stack
React 18 | Vite | Context API + useReducer | Recharts | localStorage | CSS Variables

## 📁 Folder Structure
src/
├── features/
├── shared/
├── context/
├── App.jsx
├── main.jsx

## ⚙️ Run Locally
git clone <repo-link>
npm install
npm run dev
